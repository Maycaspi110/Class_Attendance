1. Course roster

A CSV file with the columns Name and Email. It stays on the server until it restarts.

    2. Attendance closed

    Check in twice: at the start of the class and again at the end. Press Start while you stand in the classroom. The phone location becomes the classroom location. Students can leave a comment about the lesson in the end check-in.

    3. Results

    Present
    Late (only the end check-in)
    Left early (only the start check-in)
    Flagged (the lecturer decides)
    Absent
    Comments about the lesson

    The file is saved as UTF-8, so Excel shows Hebrew names correctly.

    4. Photo count (a second check)

    Take a photo of the classroom. The AI counts the people and compares the number with the check-ins. It is a rough count and only a warning: you decide. The photo is not saved.

    The AI counting is not set up on this server yet (GEMINI_API_KEY is missing).

    5. Poll

    Open a poll at the end of the class. Students answer on the check-in page.
