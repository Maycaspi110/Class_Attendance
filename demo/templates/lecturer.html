Course roster

A CSV file with the columns Name and Email. It stays on the server until it restarts.

    Attendance closed

    Check in twice: at the start of the class and again at the end. Press Start while you stand in the classroom. The phone location becomes the classroom location. Students can leave a comment about the lesson in the end check-in.

    Results

    Present
    Late (only the end check-in)
    Left early (only the start check-in)
    Flagged (the lecturer decides)
    Absent
    Comments about the lesson

    The file is saved as UTF-8, so Excel shows Hebrew names correctly.

    Photo count (a second check)

    Take a photo of the classroom. The AI counts the people and compares the number with the check-ins. It is a rough count and only a warning: you decide. The photo is not saved.

    The AI counting is not set up on this server yet (GEMINI_API_KEY is missing).

    Lesson summary (only you see it)

    Upload a short recording of the class (a screen recording or a Zoom recording), or paste a link to a public YouTube video. The AI writes a short summary. Students never see it. Nothing is saved except the summary. For the demo, use a recording of about 2-5 minutes.

    The AI summary is not set up on this server yet (GEMINI_API_KEY is missing).

    Poll

    Open a poll at the end of the class. Students answer on the check-in page.

    Publish an assignment

    Upload the PDF of the assignment. The AI reads it and checks that the due date inside the document is the date you choose. Students then choose the assignment from a list on the homework page. Publish again with the same name to fix it.

    The AI is not set up on this server yet (GEMINI_API_KEY is missing).

    Homework report (only you see it)

    On the due date, the AI reads the works of all the students together and writes one report: do the works match the assignment, which mistakes repeat, what was not clear, and what was interesting. It is not written about each student, and no names are shown.

    The AI report is not set up on this server yet (GEMINI_API_KEY is missing).
